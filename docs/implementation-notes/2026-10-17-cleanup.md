## Excerpt 25: runtime/injectables.md, line 63

Source: [runtime/injectables.md](https://github.com/hhenson/hgraph_spec/blob/95292403cd8066a375b6747609f868402616f123/runtime/injectables.md#L63).

> The agreed [language capability contract](https://github.com/hhenson/hgraph_spec/blob/main/language/docs/design/native-interfaces.md#implementation-parts-and-injectables)
> also permits context services in value functions. Its requirements are visible
> to the checker, without adding caller-supplied arguments. Selected native implementation parts declare their own requests; only those
> services need provisioning. Helpers borrow access for the call and acquire no node of their
> own. Calls silently upgrade the caller's injectable list. The C++ compiler
> supports value-helper logger/clock forwarding from the selected part.

## Excerpt 26: runtime/node.md, line 135

Source: [runtime/node.md](https://github.com/hhenson/hgraph_spec/blob/95292403cd8066a375b6747609f868402616f123/runtime/node.md#L135).

> **State** is a private value. It exists from instantiation until disposal,
> it is read and written only by the node, it never ticks, and nothing outside
> the node can see it. It is a cache: a node must behave the same whether its
> state survived or was rebuilt from equivalent inputs, recordable history and
> pending work. The same future events must give the same observations and
> effects. A lost running total is not a cache. Native `State` does not enforce
> this distinction.

## Excerpt 27: runtime/node.md, line 160

Source: [runtime/node.md](https://github.com/hhenson/hgraph_spec/blob/95292403cd8066a375b6747609f868402616f123/runtime/node.md#L160).

> In HGL, `state` is recordable state and `cache` is state. HGL hides the
> intended machinery: to the code, a `state` is a variable that is read and
> assigned, and that it is a time-series underneath — ticking, recordable, restorable —
> does not show. Mixed HGL state/cache lowering remains separate work; see
> [implementation evidence](https://github.com/hhenson/hgraph_spec_audit/blob/main/runtime/evidence.md).
